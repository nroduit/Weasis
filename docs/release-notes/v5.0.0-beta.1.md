# Weasis 5.0 beta 1 — preview, not for clinical use

> Skeleton of the tester notes of beta 1; each section is filled before the tag.

## What this preview is

A preview of Weasis 5 for the invited expert panels, plugin developers and testers.
It is not for clinical use.
It installs beside Weasis 4.x, keeps its own settings folders, never touches `~/.weasis` and does
not take over the `weasis://` links, which keep opening the installed release.
To remove it, uninstall *Weasis 5.0.0* with the tools of the operating system.
