# Auramed branding assets

Local copy of the Auramed visual identity used to rebrand this Weasis fork as **Auramed Weasis**.

| File | Purpose |
|------|---------|
| `auramed-logo.png` | Source logo downloaded from clinicasauramed.com (1024×319) |
| `auramed-logo-about.png` | Wide banner used for About / splash-style surfaces |
| `auramed-logo-square.png` | Square crop/fit for round badges |
| `auramed-logo-button.png` | Small toolbar-sized variant |

Runtime UI logos are published under:

- `../svg/logo/Weasis.svg` — small app icon
- `../svg/logo/WeasisAbout.svg` — About SVG fallback
- `../images/about.png`, `about-round.png`, `logo-button.png` — raster assets

Source URL (reference only; the app must not depend on it at runtime):

`https://clinicasauramed.com/wp-content/uploads/2023/04/auramed-clinicas-madrid-1024x319.png`
